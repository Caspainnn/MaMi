# 斩杀计划 LeetCode APP - UI 原型代码

## 项目简介

本项目为码秘 UI 设计原型示例，共包含 14 个页面的 HTML+CSS 静态实现。每个页面对应一张设计图，均为独立单文件，CSS 全部内嵌，无外部依赖，可直接用浏览器打开预览。

## 设计规范

- **布局尺寸**：移动端竖屏 375px × 812px（iPhone X 尺寸）
- **主色调**：紫色渐变 `#5B5BFF → #7C7CFF`
- **辅助色**：
  - 绿色 `#22C55E`：简单难度、通过状态、打卡完成
  - 黄色/橙色 `#FBBF24 / #F59E0B`：中等难度、通过记录卡片
  - 红色 `#EF4444`：困难难度
  - 浅紫 `#A78BFA`：复刷柱状图
- **圆角风格**：卡片 16-20px 圆角，按钮胶囊形
- **底部导航**：首页🏠、题库📖、统计📊、我的👤

## 使用说明

1. 仅为示例所用，具体项目应该根据情况灵活变化
2. 所有页面均为纯 HTML+CSS 静态实现，无需服务器、无 JavaScript 依赖
3. 页面固定宽度 375px，居中展示，模拟移动端竖屏效果

## 技术实现

- 纯 HTML5 + CSS3，无框架依赖
- CSS 全部内嵌在 `<style>` 标签中，单文件即可运行
- 使用 emoji 作为图标占位，SVG 用于简单图形元素
- 底部导航使用 `position: absolute` 固定在容器底部
- 渐变背景使用 `linear-gradient` 实现
- 环形进度图使用 `conic-gradient` + `mask` 实现
