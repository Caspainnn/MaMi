# 码秘 MaMi

码秘（MaMi）是一份面向算法面试刷题与记忆管理的产品企划和 UI 原型。它不提供在线判题，而是帮助用户在外部 OJ 完成题目后，记录本次表现、安排后续复习，并通过计划和掌握等级管理长期学习进度。

当前仓库处于小程序第一阶段开发阶段：已具备原生小程序工程、底部导航、云端题库浏览/搜索/分类、题目详情、统计和个人中心基础页面，以及微信云开发用户身份初始化。计划、提交记录和 AI 分析仍待后续阶段实现。

## 核心功能

- **斩杀计划**：选择题库后按目标天数或每日新刷量生成学习量预估。
- **新刷与复刷**：新刷遵循题库顺序；复刷按照逾期优先、当日到期其次的规则生成。
- **刷题复盘**：记录回忆结果、耗时、代码和总结；用户将外部 OJ 的结果映射为本项目枚举。
- **掌握等级**：通过状态行为表维护 Lv0–Lv5 的掌握程度和实际复刷时间。
- **斩杀机制**：用户确认完全掌握后可将题目移出后续任务。
- **数据统计**：展示学习进度、打卡及提交记录。

适用于个人算法面试准备、按题库完成系统刷题，以及需要间隔复习管理的学习场景。

## 环境依赖与运行要求

### 当前静态原型

- 支持 HTML5、CSS3 的现代浏览器。
- 无 Node.js、包管理器、数据库或第三方依赖。
- 页面以 375 × 812 的移动端竖屏尺寸设计，建议使用浏览器设备模拟模式预览。

### 小程序工程化时

仓库已包含微信开发者工具生成的 `project.config.json`，项目类型为 `miniprogram`，并已配置 AppID。当前采用原生微信小程序语法（JavaScript、WXML、WXSS），不依赖小程序端 npm 包。云开发已接入用户身份初始化：`app.js` 绑定环境 ID，`cloudfunctions/login` 负责首次创建用户记录。计划、题库、提交记录等业务数据仍将在后续阶段接入。

- 微信开发者工具及有效 AppID；
- 后端或微信云开发环境，用于用户、计划、题库、提交记录和 AI 分析数据；
- 可访问的 AI 服务端接口及服务端密钥配置；密钥不得写入小程序前端代码；
- 外部题目跳转方案及域名可用性验证。

## 快速启动

### 预览静态原型

1. 在文件管理器中打开 `项目原型代码/01_home.html`。
2. 使用浏览器直接打开，或通过 VS Code Live Server 等静态文件服务预览。
3. 其他 HTML 文件代表不同页面或状态，可分别打开查看。

无需安装依赖，也无需执行构建命令。

### 落地为微信小程序

1. 在微信开发者工具中导入本仓库根目录；工具会读取 `project.config.json`。
2. 分别右键 `cloudfunctions/initDB`、`cloudfunctions/login`、`cloudfunctions/importQuestions` 和 `cloudfunctions/getQuestionBank`，选择“上传并部署：云端安装依赖”。详细操作见 [云开发初始化](docs/云开发初始化.md)。
3. 在开发者工具的云函数测试面板执行一次 `initDB`；它会在云端创建集合、索引和默认题库记录。
4. 完成题库导入后点击“编译”，题库页会读取云端真实题目数据；若云函数未部署或不可用，页面会自动降级为本地演示数据。“我的”页面会通过云函数创建或读取用户身份。
5. 按 [数据表](项目骨架描述/数据表.md) 建立数据表、索引及题库导入脚本。
6. 导入两个 CSV 题库，并为题目写入题库顺序。
7. 将 [配置表](项目骨架描述/配置表.md) 中的状态行为表和运行规则实现为服务端或云函数逻辑。
8. 以 `项目原型代码/` 中的页面为视觉和交互参考，继续完善页面。
9. 在真机上验证登录、计划创建、提交、斩杀、跨日复刷和外部链接跳转。

## 开发说明

- 计划算法只负责创建时的工作量和完成日期预估；实际复刷日期以状态行为表为准。
- 每个用户同一时间仅保留一个启用计划。创建新计划会覆盖旧计划；重置计划不删除历史提交记录。
- 同一题允许重复提交，每条提交独立统计并对应一条 AI 分析；同一题在同一自然日最多升级一级。
- 任意成功保存的提交记录即视为当日打卡。
- “斩杀”是用户主动确认的免后续复刷操作：题目会设为 Lv5 并移出首页任务，但不生成提交记录、不调用 AI、也不计打卡。
- 本项目不做在线判题。用户应根据外部 OJ 结果选择“鼠鼠不会 / 有点印象 / 差一捏捏 / 独立通过”。

## 注意事项

- CSV 是题库源数据。导入时应校验 `题库 ID + 题目 ID` 唯一性，并保留题库顺序字段。
- 用户代码、复盘内容和 AI 请求属于用户学习数据；生产环境应由服务端处理访问控制、额度、日志脱敏和密钥管理。
- 外部 LeetCode 链接能否在小程序内打开取决于平台能力和域名配置，应在开发早期真机验证，并准备复制链接或浏览器打开的降级方案。
- 静态原型中的页面展示的是设计状态，不等同于已实现的前端逻辑或后端接口。
- `project.private.config.json` 用于本机开发者工具偏好；团队协作时不应依赖其内容，必要时应加入 `.gitignore`。
