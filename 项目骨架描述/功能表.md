# 功能表

## V1 计划生命周期

| 功能 | 规则 |
| --- | --- |
| 创建计划 | 选择题库和规划方式，展示一次性预估后创建并启用计划。 |
| 新建计划 | 用户确认后创建新计划；原 `active` 计划改为 `covered`，不删除历史记录。 |
| 重置计划 | 在“我的-斩杀计划”中提供“重置计划”入口，二次确认后将当前计划改为 `reset`，首页不再展示该计划任务；用户随后重新创建计划。 |

V1 不提供计划编辑、暂停、动态预测或补卡。

斩杀按钮保留：用户二次确认后，将题目设为 Lv5 并移出后续任务；详细数据更新和例外规则见【配置表-V1 运行规则-斩杀按钮】。
