## 已确认规则

- 本项目不做在线判题；WA / CE / RE / TLE 仅用于帮助用户选择“差一捏捏”等回忆结果。
- 同一题允许重复提交，每条提交记录独立保存；AI 分析在第四阶段一对一接入。
- 用户同一题、同一自然日最多升一级；降级不受此限制。
- 新刷当天为第 0 天；理想复习节点为第 1、3、7、15 天。
- 打卡以成功保存至少一条提交记录为准。

## 阶段结论

第三阶段验收通过。提交记录、等级状态、斩杀、打卡和统计页已完成；首页复刷任务的人工验收移交第四阶段。
