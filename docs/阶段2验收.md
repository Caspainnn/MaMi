# 阶段 2 验收记录：计划与每日任务闭环

本阶段在 `master` 第一阶段验收通过后开始。每完成一个独立功能项，先由用户验收，再继续下一项。

| 待验收项目 | 实际验收情况 |
| --- | --- |
| 从“我的”进入斩杀计划，并在云端题库中选择题库 | 待验收 |
| 选择“按目标天数”或“按每日新题数”，显示一次性计划预估 | 待验收 |
| 创建并启用计划，按题库顺序生成计划题目 | 待验收 |
| 创建新计划覆盖旧 `active` 计划 | 待验收 |
| 重置计划并在首页显示无计划引导 | 待验收 |
| 首页展示当前计划的今日新刷任务 | 待验收 |
| 当前计划绑定题库；无提交记录时复刷区显示空态 | 待验收 |

## 已确认规则

- 一个用户同一时间最多只有一个 `active` 计划；新建计划将旧计划标记为 `covered`，不删除历史数据。
- 重置计划将当前计划标记为 `reset`，不删除历史提交记录。
- 两种计划算法仅用于创建前的预估展示；预计完成日期只计算一次，不参与后续动态预测。
- 新刷按题库原始顺序；复刷的“逾期优先、今日安排其次”规则在第三阶段接入用户题目状态后实现。
