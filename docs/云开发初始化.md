# 云开发初始化（阶段 1）

本项目当前绑定的云开发环境 ID 为 `cloud1-d7gwckvr53001d8bc`。小程序启动时会调用 `login` 云函数，首次登录会自动在 `users` 集合创建用户记录。

数据库集合和索引使用云端 `initDB` 云函数初始化，不需要在控制台逐个手工创建字段。CloudBase 是文档数据库，字段会在业务记录首次写入时自动形成。

## 在微信开发者工具中部署

1. 打开项目后，确认工具顶部显示的 AppID 与云开发环境可用。
2. 分别右键 `cloudfunctions/initDB`、`cloudfunctions/login`、`cloudfunctions/importQuestions` 与 `cloudfunctions/getQuestionBank`，选择“上传并部署：云端安装依赖”。
3. 打开云函数 `initDB` 的测试面板，使用空 JSON 参数 `{}` 执行一次。
4. 确认返回值中的 `success` 为 `true`。
5. 在模拟器或真机重新编译项目，打开“我的”页面；首次调用成功后，云开发控制台的 `users` 集合会出现一条记录。

`initDB` 不会删除已有集合、数据或索引；重复执行时只跳过已存在的资源。

## 初始化内容

`initDB` 会在云端创建全部已确认的集合与索引，并写入两条默认题库记录。集合和索引通过 CloudBase 管理 SDK 在云函数环境中创建，平台会自动注入临时凭证；不需要配置或保存固定腾讯云密钥。该函数只供开发期从开发者工具手动执行；小程序页面不会调用它。

## 导入完整题库

`cloudfunctions/importQuestions` 包含从两个 CSV 生成的 242 道题目数据：LeetCode Hot 100 100 道、代码随想录 142 道。导入函数会幂等写入 `problems` 与 `question_bank_problems`；重复执行会更新已有文档，不会产生重复关系。为适配测试面板的短等待窗口，函数以 50 道题为一批并发写入。

1. 右键 `cloudfunctions/importQuestions`，选择“上传并部署：云端安装依赖”。该函数已配置 60 秒超时，并按每批 50 条并发导入。
2. 在测试面板使用空参数 `{}` 运行。每次调用会自动续传下一批 10 题；无需填写进度参数。若单次批量测试可承受，可传入 `{"bankCode":"leetcode-hot-100","start":0,"limit":100}` 一次写入完整 LeetCode Hot 100。
3. 每次预期返回 `success: true`、`total: 10`、`writtenProblems: 10`、`relations: 10`，并提示再次使用 `{}` 继续。
4. 重复运行 `{}`，直至返回 `completed: true` 与“全部题库已导入，无需继续执行”。当前已成功导入首批 10 题，预计还需运行 24 次。
5. 在云开发控制台确认 `problems` 有 242 条记录，`question_bank_problems` 有 242 条记录。

题库页面改为读取这些云端数据属于下一项开发，当前页面仍使用阶段 1 演示数据。

## 阶段 1 集合与索引

阶段 1 实际读写的集合仅为 `users`；初始化脚本会预创建后续阶段已确认的数据集合，以避免后续手工建表。

| 集合 | 用途 | 必要索引 |
| --- | --- | --- |
| `users` | 微信用户身份与累计学习数据 | `openid` 升序、唯一 |

推荐权限：将 `users` 配置为“仅创建者可读写”。阶段 1 所有创建和查询都由云函数处理，不需要开放客户端数据库权限。

## 后续阶段预留集合

阶段 2 开始前，依据 [数据表](../项目骨架描述/数据表.md) 创建以下集合：

`question_banks`、`problems`、`question_bank_problems`、`study_plans`、`plan_problems`、`user_problems`、`practice_records`、`ai_analyses`、`daily_situations`。

题库导入、计划读写权限和业务记录写入将在对应阶段实现时接入。
